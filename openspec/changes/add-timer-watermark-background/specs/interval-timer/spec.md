# Spec Delta

## ADDED Requirements

### Requirement: Show the team logo as an interval timer watermark
The interval timer interface SHALL display the Spånga handball logo as a subtle background watermark while keeping the timer readout, round status, and controls clearly legible and usable.

#### Scenario: View the interval timer
- **WHEN** the interval timer is displayed before, during, or after a session, including its startup countdown
- **THEN** the logo appears behind the timer interface without obscuring its readout, round status, or controls
